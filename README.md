# ☀️ 자외선(UV) 차단제 광화학 분석 및 피부 손상 위험도 예측 시스템
> **Raspberry Pi Pico 기반 물리·화학·생명 융합 피지컬 컴퓨팅 프로젝트**

---

## 📌 1. 프로젝트 개요 (Overview)
일상생활에서 자외선 차단제의 정량 도포 및 재도포 시점을 판단하기 어려운 문제를 해결하기 위해 기획된 연구 프로젝트입니다. 

라즈베리 파이 피코(Raspberry Pi Pico)와 환경 센서를 결합하여 **유기 자외선 차단제(흡광-열전환) 및 무기 자외선 차단제(물리적 산란)**의 시간 경과 따른 차단력 감쇄를 정량 분석하고, 실시간 피부 손상 위험도를 알림 시스템(OLED, RGB LED, Buzzer)으로 출력합니다.

---

## 🔬 2. 핵심 학술 개념 (Science Concepts)

### 🧪 화학 (Chemistry)
* **유기자차 메커니즘:** 벤젠고리 화합물(옥티녹세이트 등)이 UV 에너지를 흡수하여 열에너지($Q = mc\Delta T$)로 환원하는 광화학 발열 반응을 비접촉 온도 센서로 입증.
* **무기자차 메커니즘:** 징크옥사이드($ZnO$), 티타늄디옥사이드($TiO_2$) 입자의 가시광선 산란 현상(백탁) 및 흡광도 변화 추적.
* **람베르트-베르 법칙 (Beer-Lambert Law):**
  $$T = \frac{I}{I_0}, \quad A = -\log_{10}(T)$$
  *( $I_0$: 빈 슬라이드 글라스 투과량, $I$: 차단제 도포 후 투과량 )*

### 🧬 생명공학 (Biotechnology)
* **UV-B 노출:** 표피 세포 DNA 손상(피리미딘 이량체, Thymine-Thymine Dimer 형성) 위험도 모니터링.
* **UV-A 노출:** 진피층 콜라겐 파괴 효소(MMP-1) 활성화 및 활성산소(ROS) 생성을 고려한 종합 피부 노화 지수 수식화.

## 🔌 3. 하드웨어 구성 (Hardware Setup)

| 부품 / 센서 명칭 | 통신 방식 / 핀 | 역할 및 측정 항목 |
| :--- | :--- | :--- |
| **Raspberry Pi Pico** | Main MCU | 센서 데이터 읽기, 수식 연산 및 상태 분류 |
| **Grove UV Sensor** | ADC (GP26) | 자외선(UV) 투과량 측정 |
| **GY-906 (MLX90614)** | I2C (SDA/SCL) | 차단제 표면 비접촉 적외선 온도 측정 ($\Delta T$) |
| **BH1750 Light Sensor** | I2C (SDA/SCL) | 가시광선 조도(Lux) 및 백탁 현상 측정 |
| **0.96" SSD1306 OLED** | I2C (SDA/SCL) | 실시간 차단율(%), 표면 온도, 위험도 출력 |
| **RGB LED & Buzzer** | GPIO | 차단 상태 표시 (초록: 안전 / 노랑: 주의 / 빨강: 위험음) |
